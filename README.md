# Vijay Karthik - Portfolio Website

A clean, responsive personal portfolio website showcasing my skills, projects, certifications, and achievements.

## Features

- **Responsive Design**: Fully responsive layout that works on all devices
- **Modern UI**: Clean and professional design with smooth animations
- **Multiple Sections**: Home, About, Skills, Projects, Certifications, Achievements, and Contact
- **Interactive Elements**: Navigation menu, contact form, and social links

## Technologies Used

- HTML5
- CSS3 (with custom animations)
- JavaScript (vanilla)
- Font Awesome icons
- Google Fonts

## Sections

1. **Home**: Introduction with name, title, and social links
2. **About**: Personal bio and education details
3. **Skills**: Technical skills categorized by type
4. **Projects**: Showcase of key projects with descriptions and links
5. **Certifications**: List of professional certifications with links
6. **Achievements**: Competitive programming achievements and contest ratings
7. **Contact**: Contact form and direct contact information

## Setup

To run this project locally:

1. Clone the repository
2. Open `index.html` in your browser

## Customization

To customize this portfolio:

1. Replace placeholder text in `index.html` with your information
2. Add your own photo by replacing the placeholder in the hero section
3. Modify colors in the CSS variables in `styles.css`
4. Update project details and links
